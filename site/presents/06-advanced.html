Docker Security

  • Rootless Mode: Run daemon as non-root
  • User Namespaces: Remap container root
  • Seccomp Profiles: Limit system calls
  • AppArmor: Mandatory access control
  • Read-only containers: Prevent writes
# Run read-only container
docker run --read-only --tmpfs /tmp nginx

# Drop capabilities
docker run --cap-drop ALL --cap-add NET_BIND_SERVICE nginx

Logging and Monitoring

# View container logs
docker logs --tail 100 --follow <container>

# Configure log driver
docker run --log-driver=json-file \
    --log-opt max-size=10m \
    --log-opt max-file=3 nginx

# Docker stats
docker stats
docker stats --no-stream

Docker Swarm

# Initialize swarm
docker swarm init

# Join swarm
docker swarm join --token <token> <manager>

# Deploy service
docker service create --name web --replicas 3 -p 80:80 nginx

# Scale service
docker service scale web=5

# List services
docker service ls

Stack Deployment

# Deploy stack from compose file
docker stack deploy -c docker-compose.yml myapp

# List stacks
docker stack ls

# List services in stack
docker stack services myapp

# Remove stack
docker stack rm myapp

Kubernetes Overview

  • Pod: Smallest deployable unit
  • Deployment: Manages pod replicas
  • Service: Network endpoint for pods
  • ConfigMap/Secret: Configuration data
  • Ingress: HTTP routing rules
kubectl get pods
kubectl get services
kubectl get deployments
