Installation Workflow

Prerequisites

  • CentOS 9 Stream running
  • Root or sudo access
  • Internet connection
  • Remove old Docker versions first
sudo dnf remove -y docker \
    docker-client docker-client-latest \
    docker-common docker-latest \
    docker-latest-logrotate docker-logrotate \
    docker-engine

Add Docker CE Repository

# Install yum-utils
sudo dnf install -y yum-utils

# Add Docker CE repo
sudo yum-config-manager --add-repo \
    https://download.docker.com/linux/centos/docker-ce.repo

# Verify
dnf repolist | grep docker-ce

Install Docker CE

# Install latest Docker CE
sudo dnf install -y docker-ce \
    docker-ce-cli containerd.io \
    docker-buildx-plugin docker-compose-plugin

# Or install specific version
dnf list docker-ce --showduplicates
sudo dnf install -y docker-ce-24.0.7

Start Docker Service

# Start and enable Docker
sudo systemctl start docker
sudo systemctl enable docker

# Check status
sudo systemctl status docker

Verify Installation

# Check Docker version
docker --version

# Run hello-world
sudo docker run hello-world

# Run interactive container
sudo docker run -it centos:stream9 /bin/bash

Post-Installation Steps

  • Add user to docker group: sudo usermod -aG docker $USER
  • Configure daemon options: /etc/docker/daemon.json
  • Set up rootless mode (optional)
  • Log out and back in for group changes

Rootless Mode

Run Docker without root privileges:

# Install dependencies
sudo dnf install -y fuse-overlayfs slirp4netns

# Create docker group
sudo groupadd docker
sudo usermod -aG docker $USER

# Install rootless Docker
dockerd-rootless-setuptool.sh install

Benefits: Improved security, no root daemon

Configure Docker Daemon

# Edit daemon.json
sudo vi /etc/docker/daemon.json

# Example configuration
{
    "storage-driver": "overlay2",
    "log-driver": "json-file",
    "log-opts": {
        "max-size": "10m",
        "max-file": "3"
    },
    "dns": ["8.8.8.8", "8.8.4.4"]
}

# Restart Docker
sudo systemctl restart docker

Common Issues & Solutions

Issue Solution
Permission denied Add user to docker group
Cannot connect to daemon Start Docker service
Image pull fails Check internet connection
Port already in use Stop conflicting service
Disk space error Clean up: docker system prune
