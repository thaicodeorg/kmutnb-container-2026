Workshop: Basic Operations

Hands-on Lab

KTU - Computer Science

Workshop Flow

graph TD A[docker run -it centos:stream9] --> B[Enter Container] B --> C[Run Commands] C --> D[Exit Container] D --> E[docker ps -a] E --> F[docker stop container] F --> G[docker rm container]

Lab Objectives

  • Run CentOS 9 Stream containers
  • Execute commands inside containers
  • Manage container lifecycle
  • Work with volumes and networks

Lab 1: Interactive Container

# Pull CentOS image
docker pull quay.io/centos/centos:stream9

# Run interactive container
docker run -it --name mycentos \
    quay.io/centos/centos:stream9 /bin/bash

# Inside container, run:
cat /etc/os-release
uname -a
hostname
whoami
id

Lab 2: Container Lifecycle

# Exit container (type 'exit')
exit

# List all containers
docker ps -a

# Restart container
docker start mycentos

# Execute command in running container
docker exec mycentos cat /etc/os-release

# Stop and remove
docker stop mycentos
docker rm mycentos

Lab 3: Working with Volumes

# Create volume
docker volume create mydata

# Run container with volume
docker run -d --name data-container \
    -v mydata:/data \
    quay.io/centos/centos:stream9 \
    sleep 3600

# Create file in volume
docker exec data-container touch /data/test.txt

# Verify file exists
docker exec data-container ls -la /data/

Lab 4: Port Mapping

# Run Nginx with port mapping
docker run -d --name webserver \
    -p 8080:80 \
    nginx:latest

# Test in browser
# http://localhost:8080

# View port mappings
docker port webserver

# Stop and remove
docker stop webserver
docker rm webserver

Expected Output

  • CentOS container runs and exits
  • Container appears in docker ps -a
  • Volume persists data
  • Nginx serves page on port 8080
