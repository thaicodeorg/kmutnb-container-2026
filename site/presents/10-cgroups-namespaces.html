Control Groups (cgroups)

  • Limit CPU usage
  • Limit memory usage
  • Control disk I/O
  • Manage network bandwidth
# Run with resource limits
docker run -d \
    --cpus="0.5" \
    --memory="256m" \
    --pids-limit=100 \
    nginx

Cgroup Resources

Resource Docker Flag Example
CPU --cpus --cpus="0.5"
Memory --memory --memory="512m"
Disk I/O --device-read-bps --device-read-bps=/dev/sda:10mb
Processes --pids-limit --pids-limit=100

Namespaces

Provide isolated views of system resources

Namespace Isolates
PID Process IDs
NET Network interfaces, IPs
MNT Filesystem mount points
UTS Hostname
USER User and group IDs
CGROUP Cgroup root directory

Namespace Demo

# View namespaces
lsns

# Run container and see PID 1
docker run --rm centos:stream9 ps aux

# Compare with host
ps aux | head -5

# View container hostname
docker run --rm centos:stream9 hostname

Docker Security Flags

# Run as non-root user
docker run --user 1000:1000 nginx

# Read-only filesystem
docker run --read-only nginx

# Drop all capabilities
docker run --cap-drop=ALL nginx

# No new privileges
docker run --security-opt=no-new-privileges nginx

Seccomp Profiles

Filters system calls a container can make

# Run with default seccomp profile
docker run --security-opt seccomp=default nginx

# Run with custom profile
docker run --security-opt seccomp=myprofile.json nginx

# Disable seccomp (not recommended)
docker run --security-opt seccomp=unconfined nginx

Image Security Best Practices

# Use specific version tags
FROM python:3.11.5-slim

# Run as non-root user
RUN useradd -r -s /bin/false appuser
USER appuser

# Use COPY instead of ADD
COPY --chown=appuser:appuser . .

Always scan images for vulnerabilities:

docker scout cves nginx:latest
